The `mono/` directory contains Latin WOFF2 files for the 20 most popular monospace families in the [Google Fonts catalog](https://fonts.google.com/?category=Monospace&sort=popularity), using its popularity metadata as of 2026-10-13. Each file was served by Google Fonts CSS at weight 400 and has its corresponding license from the [Google Fonts repository](https://github.com/google/fonts) beside it. The raw TODO.txt editor defaults to JetBrains Mono; selecting another family loads only that font file.
