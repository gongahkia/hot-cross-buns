# a-slow-walk Megastructure Context Pack

Copy the contents of this directory into the root of the existing repository.

Recommended first use:

1. Review the documents.
2. Commit them as a design-only commit.
3. Open the coding agent in the repository root.
4. Paste the contents of `CODEX_START_PROMPT.md`.
5. Select one open megastructure roadmap issue.
6. Review its validation before authorizing dependent work.

Files:

- `docs/megastructure-design-spec.md`
- `docs/megastructure-technical-design.md`
- GitHub megastructure roadmap issues `#241`–`#248` and `#250`–`#262`
- `CODEX_MEGASTRUCTURE_HANDOFF.md`
- `CODEX_START_PROMPT.md`
