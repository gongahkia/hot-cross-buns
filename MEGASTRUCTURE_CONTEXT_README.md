Copy the contents of this directory into the root of the existing repository.

Recommended first use:

1. Review the documents.
2. Commit them as a design-only commit.
3. Open the coding agent in the repository root.
4. Paste the contents of `CODEX_START_PROMPT.md`.
5. Let the agent complete Milestone 0 only.
6. Review its audit before authorizing Milestone 1.
