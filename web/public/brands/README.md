# Integration logo assets

These marks identify implemented backend adapters, not connected or authenticated accounts. Custom HTTP, webhook, MCP, and OpenAI-compatible endpoints retain generic Lucide icons.

PNG assets are served locally; no browser requests go to a logo CDN. Original brand colors are preserved. Trademarks remain with their respective owners.
