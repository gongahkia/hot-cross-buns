Hot Cross Buns for Mac

Hot Cross Buns is a small desktop client for Google Calendar and Google Tasks.

Hot Cross Buns keeps the useful parts close…

  • Google Calendar events, calendars, and recurring-event instances
  • Google Tasks lists, subtasks, due dates, completion, moves, and ordering
  • Local search, batch edits, batch deletes, and offline mutation recovery
  • An optional Notes view for ordinary Google Tasks without a due date

…with deliberate local behavior…

  • A local SQLite cache for fast startup and offline viewing
  • Google as the authority for synced tasks and events
  • Calendar recurrence preserved as Google provides it, including exceptions
  • HCB-managed repeating Tasks represented by a visible, portable marker in Google Task notes

…and a setup you control.

  • Your own Google Cloud Desktop OAuth client
  • Only Google Tasks and Google Calendar scopes
  • A temporary localhost callback for sign-in
  • No client secret entered into Hot Cross Buns

Before connecting Google

  1. Create a Google Cloud OAuth Desktop app client.
  2. Enable Google Tasks API and Google Calendar API.
  3. Paste only the client ID into Hot Cross Buns Settings.

The macOS preview is not release-accepted yet. Linux and Windows support are deferred until macOS real-account acceptance and distribution are complete.
